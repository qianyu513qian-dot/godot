AoE Lite 3D
===========
Godot 4.7 Forward+ project — angled top-down 3D with DirectionalLight3D real shadows.

Ported from FirstGame (2D iso):
- Resources: Meat / Wood / Stone / Gold
- Town Center hub range + Relay
- Villagers: move / gather / deposit / build place
- Ages stub (research.gd)
- Chinese UI HUD

Controls:
- WASD / arrow keys / edge scroll — move camera
- Mouse wheel — zoom
- LMB — select / place building
- RMB — move / gather
- Select TC — train villager / age up
- Select villager — build menu

Run:
  Godot_v4.7.1-stable_win64.exe --path "C:\Users\cc\Documents\GodotProjects\AoELite3D"
  Godot_v4.7.1-stable_win64.exe --path "..." -- --screenshot
